# Provenance

`DoneGate` is a generic, clean-room reimplementation of coding-agent worktree and task-state infrastructure patterns identified during an internal workflow audit.

This repository does not contain internal domain models, financial data, private project files, credentials, or copied third-party source. Runtime code is authored for this repository and depends on Python's standard library plus PyYAML. Development dependencies are declared separately in `pyproject.toml`.

The project name and source tree do not claim affiliation with any model provider or private application.
